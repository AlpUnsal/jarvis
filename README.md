# Jarvis

Inspired by Tony Stark to build an agent that can do tasks on my laptop through text/voice inputs.

## Motivation

LLMs are getting extremely good at coding tasks, to the point where basic queries are very unlikely to be incorrect. 

Building on this idea, I decided to try to have the LLM write code that will be run directly on my laptop. 

The idea is that instead of allowing the agent to have access over my entire computer, it indirectly has access through the code it writes.

Since you can achieve most things through code (and using the terminal), Jarvis has the ability to achieve most basic tasks.
